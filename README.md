## Overview

This project is my personal portfolio, designed to introduce me as an aspiring full-stack developer. It presents my educational background, technical skills, project work, and contact information in one place.

The website uses a creative, space-inspired visual theme to provide a distinctive browsing experience.

## Features

- **Personal introduction:** Displays my background, current studies, and development interests.
- **Skills showcase:** Presents programming languages, web technologies, and concepts I am learning.
- **Project gallery:** Displays project descriptions, their status, and listed technologies.
- **Education section:** Showcases my degree, university, and academic information.
- **Contact section:** Provides an email address and a form that prepares a message in the visitor's email application.
- **Section navigation:** Allows visitors to navigate between the main portfolio sections.

## User Actions

Visitors can perform these three actions:

1. **Explore my portfolio:** Navigate through the About, Skills, Projects, Education, and Certifications sections.
2. **View my projects:** Read project descriptions and check the project status displayed on the website.
3. **Contact me:** Enter their name, email, and message to open their email application with a pre-filled message.

*Note: The contact form prepares an email; it should not be described as a backend-powered message submission system unless that functionality is implemented and verified.*
